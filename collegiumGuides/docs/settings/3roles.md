# Project Role Definitions

## Overview

The Collegium platform allows several levels of access to manage projects. A single user can be one or more of these, but the intent is to provide checks and balances on project implementation. More than one user is involved in making important decisions, like recommending a bid is a different person from who approves a bid.

## Senior Management Team (SMT)

Senior Management Team can award bids, send work authorisations, approve invoices and mark them paid, manage project team members, and edit project details.

## Project Management Team (PMT)

Project Management Team can recommend bids for approval,review invoices, interact and approve RFIs, manage project team members, and edit project details.

## Project Implementation Team (PIT)

Project Implementation Team can interact with and approve RFIs

## View Only

View Only users can view project information but cannot make changes.
